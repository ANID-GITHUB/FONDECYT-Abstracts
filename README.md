# FONDECYT-Abstracts

<p align="justify">
Con el objetivo de avanzar en la transparencia y el acceso a la información sobre el quehacer científico nacional, la Agencia Nacional de Investigación y Desarrollo (ANID) pone a disposición un fichero con las Abstract correspondientes a proyectos adjudicados en los concursos del Fondo Nacional de Desarrollo Científico y Tecnológico (Fondecyt). Esta información complementa los datos ya disponibles sobre proyectos adjudicados y postulaciones, y está orientada exclusivamente a fines estadísticos y de análisis agregado. Contenido del fichero El fichero contiene información sistematizada para cada proyecto adjudicado, incluyendo: 
</p>

<ul style="text-align: justify;">
 <li>codigo_proyecto </li>
 <li>	nombre_concurso  </li>
 <li>	nombre_archivo  </li>
 <li>	url (acceso) </li>
</ul>

<p align="justify">
Importante: Solo se incluyen proyectos que han sido adjudicados, es decir, beneficiarios formales de financiamiento. 
</p>
